# AppHarn Vision

## Mission

Make splitting expenses simple.

## Vision

AppHarn is a collection of simple tools that help people split money fairly.

## Core Principles

- **Fast**
- **No Login**
- **Mobile First**
- **Free**
- **Accurate**

## Products

- Split Meal
- Split Taxi
- Split Trip
- Split Rent
- Split Shopping
- Split Utilities

Split Meal is the one built so far — this repo. The rest are the direction, not
yet code.
